# 🤖 Kinyarwanda Voice Assistant

A simple voice assistant that listens, understands, and responds in Kinyarwanda using AI.

## 🎯 Features
- KinyaWhisper ASR (speech → text)
- Basic NLP question matching
- gTTS Kinyarwanda speech output

## 🔧 How to Run
```bash
pip install -r requirements.txt
python main.py
